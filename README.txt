Melamine Colorimetric Data Repository

Publish all files and the images folder together using GitHub Pages or another static web host.
For local preview run: python -m http.server 8000 (inside this directory), then visit http://localhost:8000
Search by Code 128 barcode ID, e.g. MEL001, or visit https://YOUR-HOST/?id=MEL001 once hosted.
The barcode scanner must act as keyboard input to the search field; scanning a Code 128 ID alone does not open a website.
For camera-based direct access, create a QR code pointing to the hosted per-dataset URL.
Do not replace the existing Code 128 payload with a URL unless the barcodes are regenerated.
